# AgentIM Android 功能边界

继承根 AGENTS.md 和产品450行规则。资料、联系人、发现、登录和配对分别放各自功能目录。`pairing` 的 View 只渲染状态/发事件；Presenter 管理 Compose/前台生命周期和本地网络权限；Controller 管理单次请求、轮询/期限、取消与 Matrix 登录交接。私有证明由数据层会话持有，禁止放入可保存状态、View快照、Intent、日志和剪贴板。返回/切换/销毁取消未完成配对，后台暂停新的轮询与消费，未知消费结果只允许新请求，不自动重放。新状态有日夜预览和受影响测试；不关闭原生未验证设备门槛以通过验收。

新身份注册只调用数据层公开 v2 接口，UI 仅持公开元数据；显示真实 open/closed/未知策略，不出现部署 permit。私有注册证明及原设备恢复由数据层持久化管理；既有账号密码登录、Agent 自主配对与创建身份各自保留入口。
